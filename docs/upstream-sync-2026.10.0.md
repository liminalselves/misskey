复审确认的两项问题是比较工具与旧基线不兼容：后端旧版输出 `built/boot/entry.js`，且缺少新版内存/堆快照 IPC；前端旧版不会生成 visualizer 统计文件。现由 `scripts/check-diagnostics-baseline.mjs` 在安装和构建 base 前检查所需能力，不给旧版补协议，也不伪造数据。

- 后端评论消费 N/A Markdown 时不再查找不存在的堆快照；前端 N/A 报告与正常报告共用 PR/SHA 元数据和上传链路。后端 base 也固定到 PR 的 base SHA，避免测量移动中的分支。
